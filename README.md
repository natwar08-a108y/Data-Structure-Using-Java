## 📌 About This Repository

Welcome to my **Data Structures and Algorithms (DSA) using Java** repository!

This repository documents my journey of learning, implementing, and practicing Data Structures and Algorithms using Java. It contains topic-wise Java programs, algorithm implementations, theoretical notes, problem-solving exercises, and mathematical concepts that strengthen programming fundamentals and algorithmic thinking.

🎯 **My Goal:** Build strong problem-solving skills, understand algorithm efficiency, develop logical thinking, and prepare for technical interviews, coding contests, and software development opportunities.

## 📂 Repository Structure

The repository is organized into topic-wise folders to make learning, revision, and navigation easier.

| Folder | Topics Covered |
|---|---|
| 📁 `Advanced Techniques in Array/` | Sliding Window and advanced array problems |
| 📁 `Array/` | Array fundamentals, ArrayList, and pattern printing |
| 📁 `Complexity/` | Time and space complexity, Master Theorem, and Akra–Bazzi |
| 📁 `Maths/` | Number theory, bit manipulation, mathematical algorithms, and their Java implementations |
| 📁 `Recursion/` | Recursion basics, arrays, patterns, permutations, and subsequences |
| 📁 `Searching in Array/` | Linear Search, Binary Search, and its applications |
| 📁 `Sorting/` | Bubble, Bucket, Counting, Insertion, Merge, Quick, Radix, and Selection Sort |
| 📁 `String/` | String fundamentals, StringBuilder, and string manipulation |

## 💻 How to Run the Programs

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Data-Structure-Using-Java.git
   ```

2. Open the project in VS Code or IntelliJ IDEA.

3. Navigate to the required topic folder.

4. Compile and execute a Java file:

   ```bash
   javac Main.java
   java Main
   ```

   Replace `Main.java` with the actual filename and use the corresponding class name when executing the program.
