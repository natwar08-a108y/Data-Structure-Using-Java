Graph Traversal: 
the process of visiting every vertex (node) and edge in a graph data structure in a systematic way.

Two primary Methods are:
1. Depth-First Search (DFS):

Algorithm: Iterative DFS Traversal using Stack (1-Based Indexing)

Input:
- V: Total number of vertices (numbered 1 to V)
- adj: Adjacency list representing the graph
- start: The starting vertex

Output:
- Prints all reachable vertices in Depth-First order.

Steps:

Step 1: Initialize Data Structures
   - Create a boolean array visited[V + 1] and initialize all elements to false (index 0 is unused).
   - Create an empty Stack S.

Step 2: Push Starting Vertex
   - Push start onto the top of Stack S.

Step 3: Traverse Until Stack is Empty
   - Repeat Steps 4 and 5 while S is not empty:

Step 4: Pop and Check Visited
   - Pop the top element from S and store it in curr.
   - If visited[curr] == false:
     - Set visited[curr] = true.
     - Print curr.

Step 5: Push Unvisited Neighbors
   - For each vertex neighbor adjacent to curr in adj[curr] (in reverse order to match recursive DFS):
     - If visited[neighbor] == false:
       - Push neighbor onto the top of Stack S.

Step 6: Stop
   - Exit when S becomes empty.

Complexity:
- Time Complexity: O(V + E)
- Space Complexity: O(V) for the visited array and explicit stack

Algorithm: Recursive DFS Traversal for Graph (1-Based Indexing using Boolean Visited Array)

Input:
- V: Total number of vertices (numbered 1 to V)
- adj: Adjacency list representing the graph
- start: The starting vertex

Output:
- Prints all reachable vertices in Depth-First (Preorder-like) order.

Steps:

Step 1: Initialize Data Structures
   - Create a boolean array visited[V + 1] and initialize all elements to false (index 0 is unused).

Step 2: Start DFS Traversal
   - Call the recursive helper function DFS(start, adj, visited).

Step 3: Inside Recursive Function DFS(curr, adj, visited)
   - Mark visited[curr] = true.
   - Print curr.
   - For each vertex neighbor adjacent to curr in adj[curr]:
     - If visited[neighbor] == false:
       - Recursively call DFS(neighbor, adj, visited).

Step 4: Backtrack and Stop
   - When all neighbors of curr are visited, return to the previous recursive call.
   - Terminate when the initial call DFS(start) finishes.

Complexity:
- Time Complexity: O(V + E)
- Space Complexity: O(V) for the visited array and recursion call stack

Algorithm: BFS Traversal (1-Based Indexing using Boolean Visited Array)

Input:
- V: Total number of vertices (numbered 1 to V)
- adj: Adjacency list representing the graph
- start: The starting vertex

Output:
- Prints all reachable vertices in Breadth-First order.

Steps:

Step 1: Initialize Data Structures
   - Create a boolean array visited[V + 1] and initialize all elements to false (index 0 is unused).
   - Create an empty Queue Q.

Step 2: Process Starting Vertex
   - Set visited[start] = true.
   - Insert start into the rear of Q (enqueue).

Step 3: Traverse the Graph
   - Repeat Steps 4 and 5 while Q is not empty:

Step 4: Dequeue and Print
   - Remove the front element from Q and store it in curr.
   - Print curr.

Step 5: Visit All Unvisited Neighbors
   - For each vertex neighbor adjacent to curr in adj[curr]:
     - If visited[neighbor] == false:
       - Set visited[neighbor] = true.
       - Insert neighbor into the rear of Q (enqueue).

Step 6: Stop
   - Exit when Q becomes empty.

Complexity:
- Time Complexity: O(V + E)
- Space Complexity: O(V)


Algorithm: BFS Traversal using Adjacency Matrix (1-Based Indexing)

Input:
- V: Total number of vertices (numbered 1 to V)
- adjMatrix[V + 1][V + 1]: 2D matrix where adjMatrix[u][v] == 1 indicates an edge between u and v (otherwise 0)
- start: The starting vertex

Output:
- Prints all reachable vertices in Breadth-First order.

Steps:

Step 1: Initialize Data Structures
   - Create a boolean array visited[V + 1] and initialize all elements to false (index 0 is unused).
   - Create an empty Queue Q.

Step 2: Process Starting Vertex
   - Set visited[start] = true.
   - Insert start into the rear of Q (enqueue).

Step 3: Traverse the Graph
   - Repeat Steps 4 and 5 while Q is not empty:

Step 4: Dequeue and Print
   - Remove the front element from Q and store it in curr.
   - Print curr.

Step 5: Scan All Possible Neighbors in the Matrix
   - Loop i from 1 to V:
     - If adjMatrix[curr][i] == 1 AND visited[i] == false:
       - Set visited[i] = true.
       - Insert i into the rear of Q (enqueue).

Step 6: Stop
   - Exit when Q becomes empty.

Complexity:
- Time Complexity: O(V^2)
- Space Complexity: O(V^2) for the matrix + O(V) for visited array and queue

> Traversing Disconnected Graphs:
When we call DFS or BFS from a starting vertex, only vertices reachable from that vertex are visited.
For a disconnected graph, some vertices may remain unvisited.
To traverse the entire graph:

for (int i = 1; i <= V; i++) {
    if (!visited[i]) {
        DFS(i, adj, visited); // Same for BFS
    }
}
Process can Produce DFS Forest or BFS Forest.

> Implementation	      Time Complexity
DFS using adjacency list 	O(V+E)
BFS using adjacency list   	O(V+E)
DFS using adjacency matrix	O(V^2)
BFS using adjacency matrix	O(V^2)

Data structure        Stack / Recursion                Queue
Traversal             Goes deep first                  Goes level by level
Shortest path         Not guaranteed                   Finds shortest path in an unweighted graph
Common applications   Cycle detection, connected       Shortest paths, level-order traversal
