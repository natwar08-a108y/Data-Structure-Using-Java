Good for small numbers.

Step-2: Generate an array of size length + 1
arr.length = largest + 1

Java Code Implementation:
import java.util.Arrays;
public class CountingSort {
public static void countingSort(int[] arr) {
if (arr == null || arr.length == 0) {
return;
}
int max = arr[0];
for (int i = 1; i < arr.length; i++) {
if (arr[i] > max) {
max = arr[i];
}
}
int[] count = new int[max + 1];
for (int i = 0; i < arr.length; i++) {
count[arr[i]]++;
}
int j = 0;
for (int i = 0; i < count.length; i++) {
while (count[i] > 0) {
arr[j] = i;
j++;
count[i]--;
}
}
}
public static void main(String[] args) {
int[] arr = {3, 4, 1, 3, 2, 5, 2, 8};
countingSort(arr);
System.out.println(Arrays.toString(arr));
}
}
Time Complexity: O(N+M) where N is time to traverse N element of original array
then M is time to traverse M element of Frequency array
