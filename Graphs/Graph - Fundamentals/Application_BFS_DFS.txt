> Are graph Bipartite?
A graph is called Bipartite if its vertices can be divided into two disjoint sets (A and B) such that:
1. No two vertices within the same set are connected by an edge.
2. Every edge connects a vertex from set A to a vertex from set B.

Important observation: 
1. Acyclic graph are always bipartite
2. A graph containing cycles is bipartite if it has no odd-length cycle.
