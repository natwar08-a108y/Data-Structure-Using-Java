MERGE SORT – TIME COMPLEXITY BREAKDOWN:

Merge Sort divides the array into 2 equal halves recursively.

N
↓
N/2 + N/2 = N
↓
N/4 + N/4 + N/4 + N/4 = N
↓
...
↓
1 + 1 + ... + 1 = N

At every level:
Total N elements are processed/merged.

Number of levels:
N → N/2 → N/4 → ... → 1

Let number of levels = k

N / 2^k = 1
⇒ 2^k = N
⇒ k log₂2 = log₂N
⇒ k = log₂N

Therefore,

Work per level = O(N)
Number of levels = O(log N)

Total Time:
T(N) = O(N) × O(log N)
     = O(N log N)

Hence:
Best Case    = O(N log N)
Average Case = O(N log N)
Worst Case   = O(N log N)

Space Complexity = O(N)
-------------------------------------------------------------------------------------------------------------------------------
RECURRENCE:
T(n) = 2T(n/2) + (n - 1)

Meaning:
- 2 subproblems, each of size n/2
- Extra work at each call = n - 1 ≈ n

Recursion Tree:

                 T(n)
              /        \
          T(n/2)      T(n/2)
             ↓           ↓
          T(n/4)      T(n/4)
             ↓           ↓
             ...
             ↓
             1

At every level, total extra work is approximately:

Level 0 → n
Level 1 → n/2 + n/2 = n
Level 2 → n/4 + n/4 + n/4 + n/4 = n
...
So, work per level = O(n)

Number of levels:

n / 2^k = 1
⇒ 2^k = n
⇒ k = log₂ n

Therefore:

T(n) = O(n) × O(log n)
     = O(n log n)

Hence:

T(n) = Θ(n log n)

NOTE:
The integral method shown in the image is an alternative way
to approximate the summation. It is not necessary to use it
when the recursion-tree method is enough.

KEY POINTS:

1. mergeSortInPlace() mainly DIVIDES the array.

2. It uses s, m, e instead of creating separate left/right
   arrays for every recursive call.

3. When a portion has only one element:
   e - s == 1
   → return

4. mergeInPlace() does the ACTUAL SORTING.

5. i points to the left half.

6. j points to the right half.

7. k points to the temporary mix array.

8. Compare arr[i] and arr[j].
   Put the smaller element into mix.

9. When one half finishes, copy the remaining elements
   from the other half.

10. Finally, copy mix back into arr[s ... e).

MENTAL MODEL:

DIVIDE
  ↓
SORT LEFT
  ↓
SORT RIGHT
  ↓
MERGE
  ↓
COPY BACK

For this example:

[8,3,4,12,5,6]
        ↓
[3,4,8] + [5,6,12]
        ↓
[3,4,5,6,8,12]


TIME COMPLEXITY:
O(n log n)

SPACE:
O(n) auxiliary space because mergeInPlace() creates:

int[] mix = new int[e - s];

The recursion stack adds O(log n).
