Why We need Backtracking?
Consider this maze to reach the target and you can go in any direction means top bottom left right up 
You are here 
      \__ ___ ___

Which we can simply do recursion?
         ("",0,0) 
              |

         /        \
       (D,1,0)     (R,0,1) 
         ____|_____          
        /    |     \    
       /     |      \   
(DD,2,0)  (DR,1,1)   (DU,0,0)  
                        |--> You are Again repeating the thing and it will never stop
                        So, Basically we must avoid simple recursion Method.
                        we are stuck in an endless loop.
                        so,We donot move back on the same path.
How to solve ? - All cells that are visited, mark them as false. So, that it does not go there.

You are here 
      \__ ___ ___
    0 |F_|___|___|
    1 |F_|F__|___|

So, Mark those cell that you visited as false so whenever This type of (DU,0,0) call happen it can avoid that.

One issue: When You are moving back the array that were marked false are currently False. This will be Problem for future case.
It will not permit any new path to move into previous covered cell.

Common sense: marking false == I have that cell in my current path.
So when that path is over, ex: you are in another recursion call, these cells should not be false.

While you are moving back, you restore the maze as it was.

Very basic recursion question:

Q: When do we go back?

A: When the function is returned.
When you come out of the recursive function -> you are now in the above recursion call.
Hence, re-mark the cell as T.
This is known as backtracking.

Grid (3x3):
   0   1   2
0 [F] [ ] [ ]
   |
   v
1 (F) [ ] [ ]
2 [ ] [ ] [ ]

• Path moves from cell (0,0) marked F to cell (1,0) marked False.
• Upon returning (backtracking), the cell status is restored back to True.

Means when you are moving out of the recursion call you make the changes that you made also become unavailable.
