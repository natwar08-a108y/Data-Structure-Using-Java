Graph: 
A graph is a non-linear data structure used to represent relationships between a collection of objects.
It is a Pair of sets (V, E) where u and v are set of vertices(Nodes) and edges respectively.

Basic Concepts:
> Order: No. of vertex.
> Size: No. of Edges.
> Parallel Edges: 
  Multiple edges b/w a single pair of vertex.
> Multigraph: 
  A graph which contain parallel edges
> Adjacent Vertices: 
  Two vertices that are directly connected by an edge.
> Degree of a Vertex:
  The number of edges incident on a vertex. In Directed graph, it is between  in-degree (incoming edges) and out-degree (outgoing edges).
   - Isolated Vertex: degree = 0
   - Pendant Vertex: degree = 1
   - Odd/Even Vertex: degree Odd/Even
   Note:
   The degree of self loop is counted twice.
> Weighted graph:
  A graph in which weights are assigned to every edge is called a weighted graph.
Ex:
  (v1) -------- 1 -------- (v2)
   |                        \
   |                         \ 2
   5                          \
   |                          (v3)
   |                         /
   |                        / 3
  (v5) -------- 4 -------- (v4)


> Path: 
  A sequence of vertices connected by edges, with no vertex repeated.  whereas in Circuit vertex may repeat but edge should not.  
  - Length of path: No. of edges in path. Trivial path in length is 0. 
> Cycle: 
  A path that begins and ends at the same vertex, forming a closed loop.        
> Connected Graph: 
  A graph in which there exists a path between every pair of vertices        
> Subgraph: 
  A smaller graph formed using a subset of the vertices and edges of a larger graph.
> Loop: 
  An edge that connects a vertex back to itself.
> Parallel Edges: 
  Two or more edges that connect the same pair of vertices.

Ex:

> Bipartite Graph:
  A graph G in which the vertex set can be partitioned into two subsets U and V such that each edge of G has one end in U and another end point in V.
  Condition:  No edges exist within Set U or within Set V.
Ex:
Set U          Set V
(u1) -------- (v1)
(u2) -------- (v2)

> Complete Bipartite graph: 
  Extension of bipartite Every element of Set U must be connected with element of Set V.
  Condition:
  U = {v1, v2 , v3, ..., vm} and W = {w1, w2, w3, ..., wn}
  The elements in these sets are the vertices.
   - There is an edge from each vi to each wj.
   - There is no self-loop.

> Wheel graph:
  A wheel graph of order 'n' is a graph obtained by joining a single 
  new vertex (the central hub) to each vertex of a cycle graph (C{n-1}) 
  of order (n-1).
Properties
• Number of vertices: |V| = n
• Number of edges: |E| = 2(n - 1)

ADDITIONAL GRAPH CONCEPTS:

1. SIMPLE GRAPH:
   A graph which does not contain self-loops or parallel edges.

2. NULL GRAPH:
   A graph which contains vertices but no edges.

3. WALK:
   A sequence of vertices connected by edges in which vertices and edges may repeat.

4. TRAIL:
   A walk in which no edge is repeated, but vertices may repeat.

5. CIRCUIT:
   A closed trail that starts and ends at the same vertex, without repeating any edge.

6. INDEGREE:
   The number of incoming edges to a vertex in a directed graph.

7. OUTDEGREE:
   The number of outgoing edges from a vertex in a directed graph.

8. DEGREE SUM THEOREM (HANDSHAKING LEMMA):
   The sum of degrees of all vertices in an undirected graph is equal to twice the number of edges.
   Formula:
   Sum of degrees = 2 * |E|
   Example:
   If a graph contains 4 edges, the sum of degrees of all vertices = 8.

9. COMPLEMENT OF A GRAPH:
   A graph formed by keeping the same vertices but adding edges wherever an edge does not exist in the original simple graph.

10. GRAPH DENSITY:
    It measures how many edges are present compared to the maximum possible number of edges.
    For an undirected simple graph:
    Density = 2|E| / (|V| * (|V| - 1))
    - Density = 1 means Complete Graph.
    - Density = 0 means Null Graph.
    - Higher density means more edges are present.
    - Lower density means fewer edges are present.


IMPORTANT PROPERTY OF BIPARTITE GRAPH
A graph is Bipartite if and only if it does not contain any odd-length cycle.

IMPORTANT RELATIONSHIPS

1. Every DAG is a Directed Graph, but every Directed Graph is not necessarily a DAG.
2. Every Complete Graph is Connected, but every Connected Graph is not necessarily Complete.
3. Every Biconnected Graph is Connected, but every Connected Graph is not necessarily Biconnected.
4. Every Complete Graph Kn (n >= 3) is Biconnected.
5. Every Complete Graph Kn is an (n-1)-regular graph.
6. A Directed Tree is a tree with directed edges. A DAG is not necessarily a tree.


CORRECTIONS TO REMEMBER

1. In an Undirected Graph, (1,2) and (2,1) represent the same edge. Do not count them twice.
2. In your six-vertex example, the graph has 6 edges and every vertex has degree 2. It is a Cycle Graph C6.
3. A Path cannot repeat vertices.
4. A Cycle is a closed path with no repeated vertices except the starting and ending vertex.
5. A Circuit is a closed trail. Vertices may repeat, but edges cannot repeat.

Application of Graph:
