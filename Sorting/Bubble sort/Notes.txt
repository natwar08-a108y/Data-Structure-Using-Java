BUBBLE SORT
===========

1. DEFINITION
Bubble Sort is a comparison-based sorting algorithm that repeatedly compares
adjacent elements and swaps them if they are in the wrong order.

For ascending order, swap arr[j] and arr[j + 1] when arr[j] > arr[j + 1].

2. EXAMPLE / DRY RUN
Original Array: [3, 1, 5, 4, 2]

Pass 1: [1, 3, 4, 2, 5]
        The largest element (5) reaches the last position.

Pass 2: [1, 3, 2, 4, 5]
        The second-largest unsorted element (4) reaches its correct position.

Pass 3: [1, 2, 3, 4, 5]
        The array becomes sorted.

Pass 4: No swaps occur, so an optimized Bubble Sort stops early.
        Final Array: [1, 2, 3, 4, 5]

Note: The example uses an optimized version with a swap flag. Without this
optimization, the algorithm may continue through all n - 1 passes.

3. HOW THE LOOPS WORK
- Outer loop (i): controls the number of passes.
- Inner loop (j): compares adjacent elements arr[j] and arr[j + 1].
- If arr[j] > arr[j + 1], swap the two elements.
- After each pass, the largest remaining unsorted element reaches the end
  of the unsorted portion.
- The inner loop becomes shorter after each pass because the sorted suffix
  does not need to be checked again.

Typical loop limits:
    for i = 0 to n - 2
        for j = 0 to n - i - 2
            if arr[j] > arr[j + 1]
                swap(arr[j], arr[j + 1])

Optimized version: use a swapped flag for each pass. If no swap occurs,
the array is already sorted, so stop.

4. COMPLEXITY
Best Case:    O(n)     when the array is already sorted AND a swap flag is used.
Average Case: O(n^2)
Worst Case:   O(n^2)   when the array is in reverse order.
Space:        O(1)     only constant extra space is used for swapping.

Bubble Sort is an IN-PLACE sorting algorithm because it sorts the array
without requiring another array of size n.

5. STABILITY
Bubble Sort is STABLE if it swaps elements only when the left element is
strictly greater than the right element (arr[j] > arr[j + 1]).
Equal elements therefore keep their relative order.

Example with tagged equal keys:
Before: [(10,A), (20,A), (20,B), (10,B)]
After:  [(10,A), (10,B), (20,A), (20,B)]

The relative order of the two 10s (A before B) and the two 20s (A before B)
is preserved.

Selection Sort is generally UNSTABLE because swapping the minimum element
with the first element of the unsorted portion can change the relative order
of equal elements.
