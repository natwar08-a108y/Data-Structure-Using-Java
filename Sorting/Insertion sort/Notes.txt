INSERTION SORT
==============

1. DEFINITION
Insertion Sort is a simple comparison-based sorting algorithm that builds the final 
sorted array one item at a time. It splits the array virtually into a sorted and 
an unsorted part.

For ascending order, an element from the unsorted part is picked and inserted into 
its correct position in the sorted part by shifting larger elements to the right.

2. EXAMPLE / DRY RUN
Original Array: [12, 11, 13, 5, 6]

Pass 1: [11, 12, 13, 5, 6]
        Key = 11. It is compared with 12 and inserted before it.

Pass 2: [11, 12, 13, 5, 6]
        Key = 13. It is compared with 12. No shift is required as it is already in position.

Pass 3: [5, 11, 12, 13, 6]
        Key = 5. Elements 13, 12, and 11 shift right, and 5 is placed at the beginning.

Pass 4: [5, 6, 11, 12, 13]
        Key = 6. Elements 13, 12, and 11 shift right, and 6 is placed after 5.
        Final Array: [5, 6, 11, 12, 13]

Note: Unlike Bubble Sort, Insertion Sort naturally adapts to already sorted data 
without needing an explicit tracking flag, as the shifting loop simply won't execute.

3. HOW THE LOOPS WORK
- Outer loop (i): steps through the unsorted portion, starting from index 1 to n - 1.
- Inner loop (j): scans backward through the sorted portion (from i - 1 down to 0).
- At each step, the current element (key) is temporarily stored.
- While the element at index j is greater than the key, it shifts one position to the right.
- Once the correct spot is found (or j reaches -1), the key is inserted at index j + 1.

Typical loop limits:
    for i = 1 to n - 1
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key
            arr[j + 1] = arr[j]
            j = j - 1
        arr[j + 1] = key

Adaptive nature: If the element is already in its correct relative position, the 
inner loop exits immediately on its very first condition check.

4. COMPLEXITY
Best Case:    O(n)     when the array is already sorted (inner loop runs constant O(1) times).
Average Case: O(n^2)
Worst Case:   O(n^2)   when the array is in reverse order.
Space:        O(1)     only constant extra space is used for the key and index variables.

Insertion Sort is an IN-PLACE sorting algorithm because it sorts the array 
without requiring another array of size n.

5. STABILITY
Insertion Sort is STABLE if the inner shifting condition stops when elements are 
equal (arr[j] > key). Because it does not shift elements past an equal value, 
identical items maintain their original relative order.

Example with tagged equal keys:
Before: [(5,A), (12,A), (12,B), (2,A)]
After:  [(2,A), (5,A), (12,A), (12,B)]

The relative order of the two 12s (A before B) is preserved.

Selection Sort is generally UNSTABLE because swapping the minimum element 
with the first element of the unsorted portion can change the relative order 
of equal elements.
