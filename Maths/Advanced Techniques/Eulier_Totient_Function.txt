EULER'S TOTIENT FUNCTION — DSA NOTES

1. Definition

Euler's Totient Function, phi(n), counts positive integers from 1 to n that are coprime to n.

Coprime means GCD(a, n) = 1.

Example:
Numbers coprime to 6 are 1 and 5.
Therefore, phi(6) = 2.

2. Important Formulas

If p is prime:
phi(p) = p - 1

For a prime power:
phi(p^k) = p^k * (1 - 1/p)

General formula:
phi(n) = n * product(1 - 1/p)

Here, p represents each distinct prime factor of n.

3. Worked Example

Calculate phi(12).

Prime factorization:
12 = 2^2 * 3

Distinct prime factors: 2 and 3.

phi(12) = 12 * (1 - 1/2) * (1 - 1/3)
         = 12 * 1/2 * 2/3
         = 4

Coprime numbers: 1, 5, 7, 11.

4. Java Code

static long phi(long n) {
    long result = n;

    for (long p = 2; p <= n / p; p++) {
        if (n % p == 0) {
            result -= result / p;

            while (n % p == 0) {
                n /= p;
            }
        }
    }

    if (n > 1) {
        result -= result / n;
    }

    return result;
}

5. Code Explanation

- result initially equals n.
- Check possible prime factors p up to the square root of the remaining n.
- If p divides n, update result = result - result/p.
- Remove all occurrences of p from n because each distinct prime factor is used only once.
- After the loop, if n > 1, the remaining n is a prime factor that has not yet been processed.
- Apply the formula to this remaining prime factor and return result.

6. Dry Run: phi(12)

Initial: n = 12, result = 12.

Prime factor 2:
result = 12 - 12/2 = 6.
Remove both factors of 2; remaining n = 3.

Prime factor 3:
result = 6 - 6/3 = 4.

Answer: phi(12) = 4.

7. Complexity

Time: O(sqrt(n)).
Auxiliary space: O(1).

8. Important Properties

- phi(1) = 1.
- For prime p, phi(p) = p - 1.
- If gcd(a,b) = 1, phi(ab) = phi(a) * phi(b).
- For n > 2, phi(n) is even.

9. Connection to Euler's Theorem

If gcd(a,n) = 1:

a^phi(n) ≡ 1 (mod n)

Example:
phi(10) = 4.
3^4 = 81 ≡ 1 (mod 10).

Fermat's Little Theorem is a special case when n is prime.

10. DSA Relevance

Totient function is useful in number theory, modular arithmetic and cryptography, particularly RSA.

It is less common as a direct pattern in standard LeetCode problems. Learn the formula, prime factorization approach and implementation rather than forcing unrelated problems.
