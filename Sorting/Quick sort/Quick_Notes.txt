Approach:
Pivot: Choose any element -> after first pass
All the elements < p will be on LHS of p.
& elements >p will be at RHS of p.

Initial array: 5, (4), 3, 2, 1   (4 is chosen as pivot p)
First pass result:, (4), [5]
Left sub-array breakdown: [1, 3, 2] -> [1, 2, (3)] -> [5]

[Middle Section: Partition Mechanism]
How to put pivot at correct position?
p = 4

Array with pointers s (start) and e (end):
s         e
5, (4), 3, 2, 1

After first swap:
   s     e
1, 4, 3, 2, 5

Final partition after loop ends:, (4), [5]

Pointers for recursion:
- Left sub-array is bounded by (low, e)
- Right sub-array is bounded by (s, high)

[Bottom Section: Logic & Code]
while a[s] < p:
    s++
while a[e] > p:
    e--

Actions:
- Swapping s & e
- Recurse on low & high sub-arrays (main array split apart)

How to pick pivot:
* Random element
* Corner elements
* Pick the middle element

[Middle Section]
Array split visualization:
[ k elements ] P [ (N - k - 1) elements ]    (Total elements = N)

Important Recurrence Relation:
T(N) = T(k) + T(N - k - 1) + O(N)

[Bottom Section]
Worst case:
k = 0

Example Array:
3, 5, 8, 9, 20, 34, 18, (66)    (where 66 is chosen as pivot)

|____________________|
      (n - 1) elements

[Top Section: Worst Case Derivation]
T(N) = T(0) + T(N - 1) + O(N)

Boxed Equation:
T(N) = T(N - 1) + O(N)

= O(N²) ==> Check S & T complex lecture for complete derivation.

[Middle Section: Best Case Recurrence]
Best case:
k = N / 2

T(N) = T(N / 2) + T(N / 2) + O(N)

Circled Equation:
T(N) = 2T(N / 2) + O(N)

[Bottom Section: Best Case Complexity]
O(N log N)
