SELECTION SORT
==============

1. DEFINITION
Selection Sort is a simple comparison-based sorting algorithm that repeatedly
selects the smallest element from the unsorted portion of the array and places
it at the beginning of that portion.

It divides the array virtually into two parts:
- Sorted part: Elements already placed in their correct positions.
- Unsorted part: Remaining elements from which the minimum is selected.

For ascending order, the minimum element is selected in every pass and swapped
with the first element of the unsorted portion.

2. EXAMPLE / DRY RUN

Original Array: [64, 25, 12, 22, 11]

Pass 1: [11, 25, 12, 22, 64]
        Minimum = 11. It is found at index 4 and swapped with 64.

Pass 2: [11, 12, 25, 22, 64]
        Minimum = 12. It is found at index 2 and swapped with 25.

Pass 3: [11, 12, 22, 25, 64]
        Minimum = 22. It is found at index 3 and swapped with 25.

Pass 4: [11, 12, 22, 25, 64]
        Minimum = 25. It is already in its correct position.

Final Array: [11, 12, 22, 25, 64]

3. HOW THE LOOPS WORK

- Outer loop (i): Represents the first index of the unsorted portion.
  It runs from index 0 to n - 2.

- Inner loop (j): Searches for the smallest element in the remaining
  unsorted portion, starting from i + 1 to n - 1.

- A variable minIndex stores the index of the smallest element found.

- If a smaller element is found, minIndex is updated.

- After the inner loop finishes, the element at minIndex is swapped
  with the element at index i.

Typical loop structure:

    for i = 0 to n - 2
        minIndex = i

        for j = i + 1 to n - 1
            if arr[j] < arr[minIndex]
                minIndex = j

        swap(arr[i], arr[minIndex])

Important:
The inner loop finds the minimum element, while the outer loop places
that minimum element at its correct position.

Total passes = n - 1

4. COMPLEXITY

Best Case:    O(n^2)   Even if the array is already sorted, all comparisons
                       are performed.

Average Case: O(n^2)

Worst Case:   O(n^2)   Comparisons remain the same regardless of input order.

Space:        O(1)     Only constant extra space is used for minIndex
                       and temporary swapping.

Comparisons:  n(n-1)/2
Swaps:        At most n - 1

Selection Sort is an IN-PLACE sorting algorithm because it sorts the
array without requiring another array of size n.

It is NON-ADAPTIVE because it performs the same number of comparisons
even when the array is already sorted.

5. STABILITY

Selection Sort is generally UNSTABLE because swapping the minimum element
with the first element of the unsorted portion can change the relative
order of equal elements.

Example with tagged equal keys:

Before: [(4,A), (4,B), (2,A)]

Pass 1: [(2,A), (4,B), (4,A)]

After sorting:
        [(2,A), (4,B), (4,A)]

The relative order of the two equal elements 4 changes
(B comes before A).

Therefore, standard Selection Sort is UNSTABLE.

6. IMPORTANT POINTS FOR VIVA

- Selection Sort repeatedly selects the minimum element.
- It requires exactly n - 1 passes for an array of n elements.
- It performs n(n-1)/2 comparisons.
- It performs at most n - 1 swaps.
- It is an IN-PLACE sorting algorithm.
- It is generally UNSTABLE.
- It is NON-ADAPTIVE.
- Best, Average and Worst Case Time Complexity = O(n^2).
