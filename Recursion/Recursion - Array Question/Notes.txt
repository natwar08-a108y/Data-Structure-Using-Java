Case 1: if arr[start] <= arr[mid]
 Check if key is also in this range :
   if key >= arr[start] & <= arr[mid]

   else:
     start = mid + 1
Case 2: if this is not (arr[start] <= arr[mid]):
Means First part is not sorted
Check if key is 2nd half means sorted half:
  if key >= arr[mid] & <= arr[end]
      start = mid + 1
