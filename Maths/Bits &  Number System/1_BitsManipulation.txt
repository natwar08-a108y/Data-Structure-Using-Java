Continuing with operators:

5) Left Shift Operator (<<)

Theory:
- Left shift moves all bits to the left by the specified number of positions.
- Zeros are inserted from the right.
- Each left shift by 1 multiplies the number by 2.
- Each left shift by n multiplies the number by 2ⁿ.
- Formula:
  x << n = x × 2ⁿ

Example:

(10)₁₀ = (1010)₂

1010 << 1 = 10100

Verification:

1 × 2⁴ + 0 × 2³ + 1 × 2² + 0 × 2¹ + 0 × 2⁰
= 16 + 4
= 20

Therefore,

1010 << 1 = 10100
(10)₁₀ << 1 = (20)₁₀

General Point:

a << 1 = 2a

General point:

a << b = a × 2ᵇ

6) Right Shift Operator (>>)

Theory:
- Right shift moves all bits to the right by the specified number of positions.
- For positive numbers, zeros are inserted from the left.
- Each right shift by 1 divides the number by 2.
- Each right shift by n divides the number by 2ⁿ.
- Any fractional part is discarded (integer division).
- Formula:
  a >> b = a / 2ᵇ

Q:

0011100 >> 1 = 0001110

(0011100)₂ = (28)₁₀
(0001110)₂ = (14)₁₀

General Point:

a >> b = a / 2ᵇ

Mask Concept:
A mask is a number with only the required bit set to 1
and all other bits set to 0.
To create a mask for the nᵗʰ bit:

mask = 1 << (n - 1) ---> Matlab n-1 no. of zeroes 1 se piche

Example:

1 << 4 = 10000

Answer:

n & (1 << (n - 1))

If the result is 0, the nᵗʰ bit is 0.
Otherwise, the nᵗʰ bit is 1.

Q2. Set the iᵗʰ bit
Set bit means 1.

Goal:
Turn the iᵗʰ bit to 1.

0 → 1
1 → 1

Mask:

mask = 1 << (i - 1)

Operation:

n | mask

Reason:
OR with 1 always makes that bit 1.

Q3. Reset the iᵗʰ bit

Goal:
Turn the iᵗʰ bit to 0.

1 → 0
0 → 0

Mask:

mask = Complement of (1 << (i - 1))

Operation:

n & mask

Reason:
AND with 0 clears the selected bit, while AND with 1 leaves other bits unchanged.

If using 0-based indexing (LSB = 0th bit), the formulas become:
mask = 1 << i
Find bit: n & (1 << i)
Set bit: n | (1 << i)
Reset bit: n & ~(1 << i)
